# QQrobot · 大肥鱼 🐟

基于 **AstrBot + NapCat + DeepSeek** 搭建的 QQ 群机器人「大肥鱼」，人设是可爱卖萌型。

## 文件说明

| 文件 | 说明 |
|------|------|
| `使用教程.md` | 从零搭建机器人的完整图文教程 |
| `大肥鱼人设.txt` | 「大肥鱼」的人设提示词，粘贴到 AstrBot 人格设置里 |

## 快速开始

1. 打开 `使用教程.md`，按步骤下载并解压 AstrBot 和 NapCat（运行库体积较大，未纳入本仓库）
2. 配置 DeepSeek API Key（模型 `deepseek-chat`）
3. 在 AstrBot 的人格设置里粘贴 `大肥鱼人设.txt` 的内容
4. 启动 NapCat 和 AstrBot，扫码登录 QQ 即可
